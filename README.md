**IA aplicada para PyMEs · Integrada a los sistemas que ya tenés**

Más de 25 años desarrollando software empresarial. Hoy lidero el área de IA en una empresa industrial y ayudo a PyMEs a sacarse de encima el trabajo manual con IA integrada a sus sistemas (.NET, SQL Server, SAP y otros ERPs), con la opción de usar modelos locales para que los datos no salgan de la empresa.

## Productos propios
Código privado · demo a pedido

- **OpenBINET** — Consultas en lenguaje natural sobre las bases SQL Server de la empresa, con métricas, exportación y seguridad por fila. La IA nunca escribe SQL: el servidor valida y arma cada consulta. *En desarrollo.*
- **DiagPyme · Suite IT para PyMEs** — Diagnóstico y seguimiento del parque informático de una PyME sin área de IT: agente en cada equipo, consola central y guías para que un técnico junior resuelva como un senior. *En desarrollo.*
- **CostOS** — Auditoría automatizada de compras para detectar sobreprecios, errores de facturación y fugas financieras en empresas medianas. On-premise. *En desarrollo.*
